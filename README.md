🚦 AI-Based Traffic Management System

An AI-powered solution to optimize traffic signal timings using YOLOv8 vehicle detection and real-time image processing.

📌 Overview:

Urban traffic congestion is a growing challenge. Traditional traffic lights operate on fixed timers, often leading to long waits and inefficient traffic flow.
This project provides an AI-driven traffic management system that:

-> Takes real-time traffic images from cameras.

-> Detects vehicles using YOLOv8 Object Detection.

-> Calculates vehicle density and count.

-> Dynamically adjusts green signal timings to improve traffic flow.

-> Runs on a Flask backend for easy deployment.

✨ Features:

🔍 Real-Time Vehicle Detection – YOLOv8-based object detection.

📊 Dynamic Signal Control – Adjusts green light duration based on detected traffic density.

🌐 Flask-Powered Web Interface – User-friendly interface to view results.

🖼 Visual Output – Displays detected vehicles with bounding boxes.

⚡ Modular & Extensible – Easy to integrate with IoT or smart city infrastructure.

🛠️ Tech Stack:

Programming Language: Python 3.8+

Backend Framework: Flask

Computer Vision: YOLOv8 (Ultralytics)

Libraries: OpenCV, Numpy, Ultralytics YOLO, Flask

Web Technologies: HTML, CSS & JavaScript
